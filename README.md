# autonomy-ladder

> Full README is authored last (SPEC §13, step 10), once results exist. This is a
> placeholder so the package metadata resolves during the no-API-key build phase.

A framework that lets an AI agent **earn the right to act without human approval**,
per task type, based on measured performance — and lose it automatically when
performance degrades. Domain-agnostic; the reference implementation is a marketing
campaign agent.

See [`SPEC.md`](SPEC.md) for the locked specification and [`AGENTS.md`](AGENTS.md)
for contributor guidance.
